# Youtube Shorts Agent

This project is designed to assist with managing and automating tasks related to YouTube Shorts. It includes various tools and scripts to streamline workflows, such as generating instructions, managing agents, and creating visuals for YouTube Shorts.

## Features

- **Instruction Management**: Load and process instructions from files for agents and scripts.
- **Agent Automation**: Automate tasks related to YouTube Shorts using the `shorts` agent.
- **Visuals Creation**: Tools to assist in creating visuals for YouTube Shorts.

## Setup Environment

1. Clone the repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Update `GOOGLE_API_KEY` in the `.env` file with your own key.

## Run

Run the following command to start the application:

```bash
adk web
```

## Start Chatting

1. Open [http://0.0.0.0:8000/](http://0.0.0.0:8000/) in your browser.
2. Select the `shorts` agent in the top left corner.
3. Start interacting with the agent to automate your YouTube Shorts tasks.
